## Agent Skills

We provide official [Agent Skills](https://agentskills.io/) designed to teach AI coding assistants (such as Claude Code, VS Code Copilot, Gemini CLI, Antigravity, and Cursor) the conventions of `svelte-jsonschema-form` v3, Svelte 5 runes, themes, validators, and SvelteKit integration.

### Available Skills

| Skill                    | Description                                                                                                                                                                       |
| :----------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sjsf-form-setup`        | Initialize `createForm`, setup `defaults.ts`, select themes/validators, handle controlled vs uncontrolled forms, and configure submissions.                                       |
| `sjsf-custom-components` | Create custom widgets, templates, and theme adapters using Svelte 5 runes (`$props`, `$bindable`), override theme components, and augment `UiOptions`.                            |
| `sjsf-schema-patterns`   | Design JSON Schema (Draft-07) and UI Schema, handle dynamic forms (`oneOf`/`anyOf` discriminators, `dependencies`, `if/then/else`), validation modes, and file uploads.           |
| `sjsf-sveltekit`         | Integrate SJSF with SvelteKit (`@sjsf/sveltekit3`), server form actions (`createAction`), client `<SvelteKitForm>` (`createMeta`), progressive enhancement, and remote functions. |
| `sjsf-v2-migration`      | Migrate SJSF codebases from v2 to v3, adapt to Svelte 5 runes, replace removed properties (`form.context`, `form.value`, `form.errors`), and update renamed packages.             |
| `sjsf-monorepo-dev`      | Monorepo development workflows: building packages, running vitest browser tests with Playwright, typechecking with Turbo, and managing changesets.                                |

### Adding Skills to Your Agent

The easiest way to install these skills into your project or global agent environment is via `npx skills`:

```bash
npx skills add https://github.com/x0k/svelte-jsonschema-form/
```

This command opens an interactive CLI that allows you to:

1. Select which skills you want to install (or install all).
2. Choose your target agent (Universal, Claude Code, Gemini CLI, Antigravity, VS Code Copilot, Cursor, etc.).
3. Choose the installation scope:
   - **Project**: Installs the skills in your current project folder for your team.
   - **Global**: Installs the skills in your user configuration directory to use across all your projects.
