Form validator implementation based on [@hyperjump/json-schema](https://github.com/hyperjump-io/json-schema).

:::note

This validator works only in precompiled mode, but neither compiling nor
restoring a validator generates code, so it can also be performed at runtime
(works with CSP
[`unsafe-eval`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/script-src#unsafe_eval_expressions)).
The dialect module (`@hyperjump/json-schema/draft-07` here), plus
`@hyperjump/json-schema/formats-lite` when a schema uses `format`, must be
imported in the browser bundle as well.

:::
