Using the following JSON Schema keywords, you can build forms that change in
response to user input.

## oneOf / anyOf

Fields `oneOf` or `anyOf` can be used as a **virtual selector**.
This selector **does not modify form data directly** but determines which schema is active.

When the form is initialized with `initialValue`, SJSF **automatically selects the most suitable schema** based on the data.

For non-object schemas, keywords declared beside `oneOf` or `anyOf` also apply to the selected option. For example, an array field's `items` and `uniqueItems`, or a string field's `format`, are inherited by every option. An option's own value of a shared keyword takes precedence, except that the stricter bound is kept.

When you switch options, values the new option can hold are carried over and its defaults are applied, including nested object and array defaults, so switching away from an option and back restores them. A value edited away from the previous option's defaults is kept as long as the new option can hold it.

## Branch defaults

When a `dependencies` or `if`/`then`/`else` branch swap replaces a property's
schema, SJSF also replaces the property's value if it still holds the `default`
or `const` declared by the branch being swapped away. A value edited away from
that default is kept, as is one that neither branch declares.

The comparison cannot tell how a value equal to the old default was supplied, so
a matching `initialValue` or controlled `value` is replaced too. Values are
matched per key of the level that declares the default, so a `default` on a
nested object replaces an untouched leaf while keeping an edited sibling, and a
`default` declared a level above keeps the whole object once any leaf is edited.
Array items are not searched, and a conditional declared inside an array item is
left alone.

## patternProperties

The `patternProperties` keyword allows you to define schemas for object properties
whose names match a regular expression. This is useful for forms with dynamic keys,
such as key-value pairs or metadata fields.
